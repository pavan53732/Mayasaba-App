Welcome to Mayasaba

Mayasaba coordinates the coding tools already on your PC and checks their work before calling it done.

Install and sign in to these tools yourself. Mayasaba does not install, update, or change their settings:

  • Hermes Agent CLI
  • Kilo Code CLI
  • Claude Code CLI

A missing tool does not stop you from opening a project folder. Once a folder is open, you can use Chat while Mayasaba shows what needs attention.

Open a project folder

Choose the folder where your work belongs.

Opening it creates or restores the project in Mayasaba. It does not install a CLI, scan the folder, start an agent, initialize Git, or approve any work.
